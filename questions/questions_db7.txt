8000
Um ponteiro é uma variável capaz de armazenar endereços de memória.
1
Correto! Ponteiros armazenam endereços de memória de outras variáveis ou regiões alocadas.
Incorreto. A principal finalidade de um ponteiro é armazenar um endereço de memória.
8001
O conteúdo armazenado em um ponteiro corresponde sempre ao valor da variável apontada.
0
Correto! O ponteiro armazena o endereço da variável, não o seu valor.
Incorreto. Um ponteiro armazena o endereço de memória da variável apontada.
8002
O operador & permite obter o endereço de memória associado a uma variável.
1
Correto! O operador & retorna o endereço da variável.
Incorreto. O operador & é utilizado para obter endereços de memória.
8003
O operador * pode ser utilizado para acessar o conteúdo apontado por um ponteiro.
1
Correto! Esse processo é conhecido como desreferenciação.
Incorreto. O operador * permite acessar o conteúdo armazenado no endereço apontado.
8004
Dois ponteiros podem apontar simultaneamente para a mesma posição de memória.
1
Correto! Vários ponteiros podem referenciar o mesmo endereço.
Incorreto. É perfeitamente possível que múltiplos ponteiros apontem para o mesmo local.
8005
Um ponteiro não inicializado possui necessariamente um endereço válido.
0
Correto! Ponteiros não inicializados contêm valores indefinidos.
Incorreto. Um ponteiro não inicializado não deve ser considerado válido.
8006
O valor NULL é frequentemente utilizado para indicar que um ponteiro não aponta para nenhum objeto válido.
1
Correto! NULL representa a ausência de um endereço válido.
Incorreto. NULL é utilizado justamente para indicar ausência de referência válida.
8007
Desreferenciar um ponteiro NULL é uma operação segura.
0
Correto! Essa operação pode causar falhas de execução.
Incorreto. Não se deve acessar o conteúdo de um ponteiro NULL.
8008
Ponteiros permitem compartilhar acesso a uma mesma região de memória.
1
Correto! Essa é uma das principais utilidades dos ponteiros.
Incorreto. Ponteiros possibilitam que diferentes partes do programa acessem a mesma memória.
8009
Uma variável comum e um ponteiro armazenam exatamente o mesmo tipo de informação.
0
Correto! Variáveis armazenam valores, enquanto ponteiros armazenam endereços.
Incorreto. Ponteiros armazenam endereços; variáveis comuns armazenam valores.
8010
A passagem por referência permite que uma função altere diretamente dados existentes fora dela.
1
Correto! Alterações feitas através de ponteiros podem afetar os dados originais.
Incorreto. A passagem por referência permite modificar os dados originais.
